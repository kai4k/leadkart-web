## C. Behaviour drift: fix while consolidating

1. **Type-to-confirm doesn't block.** `ConfirmDialog` has no `confirmDisabled`, so the confirm button in AnonymiseDialog and DeleteRoleDialog stays clickable on a mismatch and then silently does nothing. Fixed by the `ReasonConfirmDialog` `confirmText` prop.
2. **Stale form state between opens.** Errors carry over to the next open, and there are four different reset strategies. Fixed by `FormSheet`/`FormDialog` resetting on open.
3. **Two error-copy regimes.** The ladder dialogs use typed copy, while `useForm.bannerError` and users/[id] / sessions show the raw `err.message`. Fixed by using `describeApiError` everywhere.
4. **Any error reads as "not found"** (OrderDetail, PermissionRequestDetail); ProductsList has no NotFound branch at all. Fixed by `QueryState`.
5. **Tenant status maps disagree.** `tenantStatusBadge` uses `pending_deletion` with fallback `info`; `tenantLifecycleBadge` uses `marked_for_deletion` with fallback `neutral`. Check against the openapi enum and keep one map.
6. **Money renders two ways** ("₹10" vs "₹10.00"). Fixed by a single `formatMoney`.
7. **Formatting copies disagree.** Three different `relativeTime` outputs; mixed locales (`en-IN`, `en-US`, default); two `displayName` fallbacks; five `initials` algorithms. Fixed by `utils/format.ts`.
8. **Bulk-result `id` field differs** across inventory, leads and orders: required in one, optional in another, `nonnegative` in the third. Fixed by one shared schema checked against openapi.
9. **Field a11y gaps.** `role="alert"` exists only on TextField errors; ids are built from the label, so they collide; textareas have no `aria-describedby` and no focus ring; ImpersonateModal uses `text-danger`. Fixed by the field layer.
10. **Search behaves differently per list.** Debounced and trimmed in one list, firing on every keystroke in the others, and missing an `aria-label` in UsersList. Fixed by `SearchInput`.
11. **Nested interactive elements.** `<a><Button>` in 6 `+error.svelte` files (Button needs `href` support); an `<a>` inside `Dropdown.Item` in RolesList; every row's menu labelled the same generic "Row actions". Fixed by Button `href`, `RowActionsMenu` and `RouteError`.
12. **Rune misuse.** routes/leads/+page wraps `createSavedViews` in `$derived`; routes/roles/[id] does `$derived(setRoleParentMutation())`. Both should be created once.
13. **Undo and reason input.** The inventory undo has no `.catch`; CancelOrderDialog takes its reason through a single-line TextField plus a synthetic submit event. Fixed by `useOptimisticMutation` and `ReasonConfirmDialog`.
14. **Rule 10.** PeopleList links to `/operator/persons/${id}`, putting a person UUID in the URL bar. Phase 3 item 4 fixes this.
